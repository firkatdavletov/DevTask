## Описание из Jira

На экране профиля добавить возможность изменить имя пользователя.
Использовать существующий API и принятый в проекте механизм редактирования профиля.
Если подходящий API в проекте отсутствует, уточнить контракт перед реализацией.

## Критерии приёмки

- После успешного сохранения новое имя отображается в профиле.
- После перезапуска приложения отображается сохранённое имя.
- При ошибке сохранения отображается сообщение, введённое имя не теряется.
- Пустое имя не отправляется на сервер.

## Материалы

Приложить экспорт макета в соседний каталог attachments/ и описать необходимые состояния.
Заменить этот текст и критерии реальными требованиями перед запуском.
